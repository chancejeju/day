# 합격까지 · 한능검 D-day

한국사능력검정시험을 준비하는 수험생을 위한 한국어 D-day 웹앱입니다. 시험일까지 남은 시간을 확인하고, 원서접수와 개인 학습 일정을 한 화면에서 관리합니다.

HTML, CSS, 순수 JavaScript로 구현했으며 별도 프레임워크, 패키지 설치, 빌드 작업 없이 정적 웹 서버에서 실행할 수 있습니다. 모바일과 맥북 화면을 지원하는 반응형 PWA입니다.

## 주요 기능

- 시험일까지 남은 날짜와 일·시·분·초 카운트다운
- 시험, 원서접수, 기타 일정 추가·수정·삭제
- 메인 화면에 표시할 대표 D-day 선택
- 일정별 메모와 날짜순 정렬
- 브라우저 localStorage를 통한 기기 내 저장
- JSON 파일을 이용한 일정 백업과 복원
- Apple 캘린더 등에서 가져올 수 있는 ICS 일정 내보내기
- 웹 앱 매니페스트, 홈 화면 아이콘, 서비스 워커를 통한 PWA 구성
- 최초 온라인 실행 및 캐시 준비 완료 후 오프라인 화면 사용

## 파일 구성

```text
hangeom-dday/
├── readme.md               # 서비스 설명과 사용법
├── widget/
│   ├── Hangeom-Widget.js   # Scriptable 소형 위젯 원본
│   └── 설치방법.md          # 아이폰 위젯 설치 안내
└── dist/
    ├── index.html          # 한국어 화면과 일정 입력 폼
    ├── style.css           # 반응형 디자인
    ├── app.js              # 카운트다운, 일정 관리, 저장 및 내보내기
    ├── sw.js               # 오프라인 화면 캐시
    ├── manifest.webmanifest # PWA 설치 정보
    ├── data/events.json    # 웹앱·위젯의 공개 기준 일정
    ├── scriptable/Hangeom-Widget.js # GitHub Pages에서 받을 위젯 코드
    ├── icon-192.png        # 홈 화면 아이콘
    └── icon-512.png        # 큰 아이콘
```

## 맥북에서 실행하기

1. ZIP 파일을 내려받아 압축을 풉니다.
2. 터미널 앱을 엽니다.
3. `cd `를 입력하고, 압축을 푼 `hangeom-dday` 폴더를 터미널에 끌어 놓은 다음 Return을 누릅니다. `cd`와 폴더 경로는 같은 줄에 입력해야 합니다.
4. 아래 명령어를 입력합니다. Python 3이 필요합니다.

```bash
python3 -m http.server 8080 --directory dist
```

5. 맥북 Safari 또는 Chrome에서 <http://localhost:8080>을 엽니다.
6. 사용하는 동안 터미널을 열어 둡니다. 종료하려면 터미널에서 Control + C를 누릅니다.

Safari에 ‘파일 → Dock에 추가’ 메뉴가 있으면 앱처럼 등록할 수 있습니다. 로컬 주소를 Dock에 추가해도 실행 중인 서버가 필요합니다. 맥북을 재시작하면 위 명령어를 다시 실행하세요.

### 실행 오류 해결

- **404 / File not found:** 실행한 위치에 `dist` 폴더가 있는지 확인하세요. 또는 `--directory` 뒤에 실제 `dist` 폴더의 전체 경로를 큰따옴표로 감싸 입력하세요.
- **permission denied와 폴더 경로:** 폴더 경로만 명령어로 실행한 경우입니다. 경로 앞에 `cd `를 붙여 같은 줄에서 실행하세요.
- **서버에 연결할 수 없음:** 터미널 서버가 실행 중인지, 주소에 `http://`와 `:8080`이 포함되어 있는지 확인하세요.
- **Address already in use:** 다른 서버가 8080 포트를 사용 중입니다. 기존 서버를 종료하거나 포트를 8081로 바꾸고 브라우저에서도 해당 포트로 접속하세요.

## 아이폰에서 설치하기

### 독립적으로 사용하는 방법

먼저 `dist` 안의 파일들을 정적 HTTPS 호스팅에 배포해야 합니다. 현재 제공되는 ZIP 자체는 온라인 배포된 서비스가 아닙니다.

1. 아이폰 Safari에서 배포된 HTTPS 주소를 엽니다.
2. 공유 메뉴에서 ‘홈 화면에 추가’를 선택합니다.
3. ‘웹 앱으로 열기’ 옵션이 보이면 켜고 ‘추가’를 누릅니다.
4. 홈 화면의 ‘합격까지’ 아이콘으로 실행합니다.
5. 온라인 상태에서 ‘오프라인 화면 준비 완료’가 표시되는지 확인합니다.

HTTPS 배포 주소로 설치하면 맥북이나 로컬 서버를 켜 둘 필요가 없습니다. 비공개 호스팅을 사용하는 경우 로그인이 필요할 수 있습니다. 최초 접속, 로그인 갱신, 캐시 재설정 등에는 인터넷이 필요합니다.

## 아이폰 소형 위젯 설치하기

웹앱의 홈 화면 아이콘과 D-day 소형 위젯은 서로 다른 기능입니다. 실제 D-day 위젯은 무료 Scriptable 앱을 사용합니다.

1. GitHub Pages에 `dist` 전체를 배포해 `https://chancejeju.github.io/day/data/events.json`과 `https://chancejeju.github.io/day/scriptable/Hangeom-Widget.js`가 열리는지 확인합니다.
2. 아이폰 App Store에서 Scriptable을 설치합니다.
3. 배포된 `Hangeom-Widget.js`를 열어 전체 코드를 복사합니다.
4. Scriptable에서 `+`를 누르고 코드를 붙여넣은 뒤 이름을 `합격까지`로 저장합니다.
5. 스크립트를 한 번 실행해 소형 위젯 미리보기와 네트워크 접근을 확인합니다.
6. 아이폰 홈 화면을 길게 누르고 `편집 → 위젯 추가 → Scriptable`을 선택합니다.
7. 소형 위젯을 추가한 뒤 길게 눌러 `위젯 편집 → Script → 합격까지`를 선택합니다.

위젯을 누르면 `https://chancejeju.github.io/day/` 웹앱이 열립니다. 갱신 희망 시각은 코드에서 요청하지만 실제 갱신 시점은 iOS가 결정합니다. 자세한 내용은 `widget/설치방법.md`를 참고하세요.

## 웹앱과 위젯의 데이터 연동

`dist/data/events.json`은 GitHub Pages가 공개하는 기준 일정입니다. 위젯은 이 파일에서 `kind`가 `exam`인 일정만 골라 한국 날짜 기준으로 가장 가까운 오늘 또는 미래 시험을 표시합니다. 미래 시험이 없으면 가장 최근 시험과 `종료` 상태를 표시합니다.

웹앱은 기존 localStorage 일정이 있으면 그 데이터를 우선하므로 배포 후에도 기존 사용자 일정이 유지됩니다. 저장된 일정이 없는 브라우저에서만 `events.json`을 초기 일정으로 불러옵니다. 웹앱에서 추가·수정·삭제한 내용은 해당 브라우저의 localStorage에만 남으며 GitHub 파일을 자동 수정하지 않습니다. 정적 GitHub Pages에서 토큰을 노출하지 않고 양방향 자동 동기화를 구현할 수 없기 때문입니다.

공통 기준 일정을 변경하려면 저장소의 `dist/data/events.json`을 수정하고 GitHub Pages에 다시 배포합니다. 위젯은 다음 네트워크 갱신 때 새 데이터를 저장합니다. 네트워크 오류가 나면 마지막으로 성공한 데이터를 사용하며, 캐시도 없으면 `일정 없음`을 표시합니다. 이미 웹앱에서 일정을 수정한 사용자는 localStorage가 우선하므로 필요하면 웹앱에서도 같은 날짜를 직접 수정해야 합니다.

### 같은 Wi-Fi에서 임시로 확인하기

맥북과 아이폰을 같은 Wi-Fi에 연결하고 맥북 서버를 실행한 상태에서, 아이폰 Safari에 `http://맥북의-IP주소:8080`을 입력합니다. 예를 들어 맥북 IP가 `192.168.0.10`이면 `http://192.168.0.10:8080`입니다. 맥북의 네트워크 설정에서 IP 주소를 확인하세요. 방화벽이나 공유기 설정에 따라 접근이 제한될 수 있습니다.

`localhost`는 현재 사용 중인 기기 자신을 뜻하므로 아이폰에서 맥북에 접속할 때 사용할 수 없습니다. 같은 Wi-Fi의 HTTP 주소는 임시 화면 확인용이며, 서비스 워커 기반 오프라인 설치 기능에는 HTTPS 배포가 필요합니다.

## 일정 관리 방법

- **일정 추가:** 이름, 유형, 날짜와 시간, 메모를 입력하고 저장합니다.
- **일정 수정:** 일정 카드의 ‘수정’을 누릅니다.
- **대표 일정:** 추가·수정 창에서 ‘대표 D-day로 설정’을 선택합니다.
- **일정 삭제:** 일정 카드의 ‘삭제’를 누르고 확인합니다.
- **백업:** ‘백업 저장’으로 JSON 파일을 보관합니다.
- **복원:** ‘백업 불러오기’로 JSON 파일을 선택합니다. 확인하면 현재 일정 전체가 백업 내용으로 바뀝니다.

## 시간 계산 기준

모든 입력과 표시는 한국 시간(Asia/Seoul, UTC+09:00) 기준입니다. D-day 숫자는 한국 달력의 날짜 차이로 계산합니다. 시험 당일에는 D-DAY, 다음 날부터는 D+1과 같이 표시합니다. 초 단위 카운트다운은 실제 시작 시각까지 남은 시간이며, 시작 시각이 지나면 0과 ‘시작 시각 경과’를 표시합니다. 기기의 날짜·시간 설정이 정확해야 합니다.

## 캘린더와 알림

일정 카드의 ‘캘린더’ 버튼은 ICS 파일을 내려받습니다. 파일에는 1일 전과 1시간 전 알림이 포함되지만, 캘린더 앱과 가져오기 방식에 따라 처리 결과가 다를 수 있으므로 등록 후 알림을 확인하세요. 종료 시간은 내보내기용으로 시작 1시간 후를 사용하며 실제 시험 종료 시간을 의미하지 않습니다.

아이폰에서 파일이 미리보기로만 열리면 파일 앱에 저장하거나 Mac/iCloud 캘린더에서 가져오거나 일정을 직접 입력하세요. 같은 파일을 여러 번 가져오면 일정이 중복될 수 있습니다.

이 앱 자체는 닫혀 있을 때 예약 알림을 보내지 않습니다. iOS 16.4 이상은 홈 화면 웹앱의 웹 푸시를 지원하지만 사용자 권한과 별도 푸시 서버가 필요하며, 현재 버전에는 해당 서버가 없습니다. [Apple 웹 푸시 안내](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers)

## 저장과 개인정보

일정은 해당 기기·브라우저·주소의 localStorage에만 저장됩니다. 일정 데이터를 별도 앱 서버로 보내거나 계정에 동기화하는 기능은 없습니다. 호스팅 제공자의 접속 기록 처리는 해당 서비스 정책을 따릅니다.

맥북과 아이폰, Safari와 홈 화면 앱, 로컬 주소와 배포 주소의 저장 공간은 서로 다를 수 있습니다. 주소를 바꾸기 전에는 백업하고 새 주소에서 복원하세요. 사이트 데이터 삭제, 개인정보 보호 모드, 저장 공간 부족, 운영체제의 저장 공간 회수 등에 따라 데이터가 사라지거나 저장이 제한될 수 있습니다.

## 현재 제한과 검증 범위

- 웹앱과 별도로 Scriptable 기반 iPhone 소형 홈 화면 위젯을 제공합니다. 네이티브 독립 앱 위젯이나 잠금화면 위젯은 아닙니다.
- 계정 로그인, 기기 간 자동 동기화, 백그라운드 예약 푸시는 제공하지 않습니다.
- 오프라인 사용은 브라우저 캐시가 유지되는 범위에서 가능합니다.
- JavaScript 문법과 한국 시간·D-day 날짜 전환·초기 렌더링·HTML 문자 처리 검사를 수행했습니다.
- 실제 아이폰에서 Scriptable 위젯의 배치·갱신, 웹앱 설치, 오프라인 재실행, 캘린더 가져오기는 사용자 테스트가 필요합니다.
